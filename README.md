# 🌱 Smart Agriculture System

An AI + IoT based Smart Agriculture System designed to monitor crop health, environmental conditions, and automate decision-making for better farming productivity.

## 📌 Overview
The Smart Agriculture System collects real-time data from sensors and cameras to analyze crop conditions, soil moisture, temperature, and humidity.  
It uses Machine Learning and Computer Vision to provide insights and alerts to farmers.

## 🚀 Features
- Crop Health Monitoring using ML
- Soil Moisture Detection
- Temperature & Humidity Monitoring
- Automated Alerts for Abnormal Conditions
- IoT Sensor Integration
- Real-Time Dashboard
- Image Processing with OpenCV
- Data Logging & Analysis
